Durante o silêncio só chegam os avisos fixos (📌).
A notificação não faz barulho ou passa despercebida?

Android: abre as Definições do telemóvel → Apps → o navegador onde usas o chat (ou «Video Team Chat» se o instalaste no ecrã principal) → Notificações → escolhe a categoria deste site → Importância «Urgente» (som e aparece no ecrã) e escolhe aí o som. Em Bateria, põe a app «Sem restrições» para as notificações não ficarem à espera com o ecrã apagado.

iPhone/iPad: as notificações só existem com o chat instalado no ecrã principal (Partilhar → «Adicionar ao ecrã principal»). Definições → Notificações → o chat → Sons e Banners «Persistentes».

O toque e a vibração acima valem quando o chat está aberto e na vibração das notificações. O som exato com a app fechada é o que o sistema escolher para este site.
